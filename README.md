# techtimes-apiv3
The backend of sitechtimes made in django
ported from https://github.com/sitechtimes/techtimes-apiv2
##
this uses uv as package manager so install uv pls and if you use nix theres a flake
### How To run
-  install uv
-  run uv venv to create venv
-  uv sync to grab dependencies
-  activate venv with .venv\Scripts\activate.bat or .venv\Scripts\Activate.ps1
- run python manage.py runserver
